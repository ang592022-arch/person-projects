# 云开发上线配置

项目已经接入云数据库、云存储和 `ocrImport` 云函数。仓库默认保留本地模式，只有完成下面配置后才能切换到正式云模式。

## 1. 创建并填写云环境

1. 在微信开发者工具打开“云开发”，创建或选择生产环境。
2. 复制环境 ID。
3. 在本机私有文件 `miniprogram/config/env.ts` 中填写 `envId`。
4. 把 `storageMode` 改成 `'cloud'`。

`env.ts` 已被 `.gitignore` 忽略，不要提交真实环境 ID、高德 Key 或任何密钥。示例见 `miniprogram/config/env.example.ts`。

## 2. 创建集合

- `users`
- `user_region_states`
- `travel_records`
- `user_preferences`
- `custom_world_cities`
- `ocr_usage`

前五个集合必须设置为“仅创建者可读写”。`ocr_usage` 只允许云函数访问。详细规则和双账号验收步骤见 `docs/cloud-database-security.md`。

## 3. 部署 OCR 云函数

1. 在开发者工具中右键 `cloudfunctions/ocrImport`。
2. 选择“上传并部署：云端安装依赖”。
3. 为云函数配置 `OCR_SECRET_ID`、`OCR_SECRET_KEY`；也可以给运行身份授予腾讯云 OCR 调用权限。
4. 确认 `ocr_usage` 集合存在。
5. 在腾讯云 OCR 控制台开通文字识别服务，并用一张非敏感测试截图完成真实识别。

函数使用腾讯云 `GeneralAccurateOCR`，每日默认限制同一 openid 调用 30 次，并为整个小程序设置每月 900 次的默认费用上限。两个计数通过数据库事务更新，识别结束后会删除临时截图。密钥只能放在云函数环境变量或运行身份中。

开通后应在 OCR 控制台“设置”中保持后付费关闭。免费资源包可能延迟发放；资源包管理页显示额度后再执行真实识别，不要为了绕过等待而开通后付费。

## 4. 数据迁移

正式切换前，先在体验版备份重要本地记录。切换云模式后，在统计页执行“迁移本地数据到云端”。迁移现在按单条日志处理：图片上传或数据库保存失败时不会生成缺图的半条记录，新上传文件会尝试回滚。

云模式下读取采用“云端优先、本地回退”：尚未迁移的本地记录仍会显示，并与云端记录按内容签名去重。云端新增、编辑和删除成功后会尽力维护本地缓存；本地缓存写入失败不会把已经成功的云写入误报为失败。迁移成功前不会自动删除原始本地记录。

陌生国外城市在云模式下会等待云端写入成功后再提示完成，避免换设备后消失。首页自定义封面会在应用主题时上传到云存储，被替换的旧封面和未保存的临时图片会进入统一清理流程。

迁移后必须验证：

- 新增、编辑、删除日志；
- 图片和视频上传、预览、删除；
- 地图点亮联动；
- 主题和自定义国外城市同步；
- 清缓存或换设备后恢复；
- 账号 A 与账号 B 数据互不可见。

## 5. 失败恢复

云图片删除失败时，文件 ID 会进入本地待清理队列，并在下次启动时重试。数据库规则、云存储权限、双账号隔离和真实删除结果仍必须在生产云环境中用真机验证，代码静态检查无法代替这一步。
