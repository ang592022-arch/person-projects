# Contributing

Thank you for helping improve Manji Travel Trace.

1. Create a focused branch.
2. Keep environment IDs, AppIDs, secrets, OpenIDs and personal travel media out
   of commits.
3. Do not submit China administrative boundary coordinates without a recorded
   source, redistribution license and compliance review.
4. Run `pnpm run check` before opening a pull request.
5. Explain user-visible changes and include focused tests where practical.

By contributing, you agree that your contribution is licensed under the MIT
license in this repository.
